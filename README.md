🌱 Sustenta São João
Este repositório contém os arquivos desenvolvidos durante o projeto Sustenta São João (2023), realizado como Trabalho de Conclusão de Curso (TCC) no Instituto Federal de Educação, Ciência e Tecnologia.
📌 Sobre o projeto
O Sustenta São João foi proposto aos alunos concluintes do curso Técnico em Informática Integrado ao Ensino Médio do campus de São João da Boa Vista, com o objetivo de desenvolver uma solução tecnológica voltada à população sanjoanense.
A plataforma foi idealizada para melhorar a comunicação entre os cidadãos e a prefeitura municipal, com foco em:
🏙️ Qualidade de vida urbana
♻️ Gestão de resíduos sólidos
🚰 Problemas relacionados ao saneamento básico
🌍 Incentivo a práticas sustentáveis
👨‍💻 Minha participação

Minhas responsabilidades incluíram:

Colaboração com a equipe no desenvolvimento geral da aplicação

🛠️ Tecnologias e ferramentas
Desenvolvimento web (HTML, CSS, JavaScript, PHP)

👥 Contexto
Este projeto foi desenvolvido em grupo como parte do Trabalho de Conclusão de Curso (TCC). Cada integrante foi responsável por diferentes módulos do sistema.
🎯 Objetivo do repositório
